# conta_bancaria

Projeto em TypeScript com menu interativo no terminal, utilizando a biblioteca `readline-sync`.

## Como executar

```bash
npm install
npm run build
npm starts
```

Ou em modo de desenvolvimento:

```bash
npm install
npm run dev
```

## Estrutura

- `src/Menu.ts` → classe principal do projeto
- `src/util/Colors.ts` → classe com cores ANSI para o terminal
